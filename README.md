## Deploy to GitHub + Vercel (step by step)

### Step 1 — GitHub
1. Go to github.com and sign in (or create free account)
2. Click the "+" button → "New repository"
3. Name it: `molina-custom-works`
4. Set to Public, click "Create repository"
5. Upload ALL files from this folder (drag and drop the whole folder)
6. Click "Commit changes"

### Step 2 — Vercel
1. Go to vercel.com and sign in with your GitHub account
2. Click "Add New Project"
3. Find and select `molina-custom-works` from your GitHub repos
4. Click "Deploy" — no settings to change
5. Done! Vercel gives you a free URL like `molina-custom-works.vercel.app`

### Step 3 — Custom Domain (optional)
1. In Vercel → your project → Settings → Domains
2. Add `molinacustomworks.com`
3. Vercel will show you DNS records to add at your domain registrar
4. Done — site goes live at your domain within minutes

## After Launch — SEO Tips
- Submit site to Google Search Console (search.google.com/search-console)
- Add the site URL, verify ownership, submit sitemap
- Google will start indexing within a few days
- Set up a Google Business Profile at business.google.com for local search

## Form Submissions

## To Update the Site
1. Edit files locally
2. Go to GitHub → your repo → find the file → click pencil icon to edit
3. Or drag new files to replace images
4. Vercel auto-deploys every time you update GitHub — no extra steps needed
